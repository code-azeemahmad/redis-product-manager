# Implement Task Workflow

1. Read `AGENTS.md` and the task's relevant architecture/API/data/security documents.
2. Inspect the repository, existing patterns, and current tests before editing.
3. Confirm task scope and acceptance criteria from `project-management/tasks.md`.
4. Make a short implementation plan and identify unresolved decisions.
5. Implement the smallest coherent change; avoid unrelated refactors and dependency additions.
6. Add/update unit, integration, or API tests for the change.
7. Run relevant tests and report exact commands and results. If a test cannot run, state why.
8. Review the diff for security issues, blocking I/O, secret leakage, API mismatch, and accidental scope expansion.
9. Update documentation, task status, progress, and changelog where appropriate.
